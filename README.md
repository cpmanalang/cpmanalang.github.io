# Manalang Accounting Website

Static GitHub Pages website for Manalang Accounting.

## Pages

- `index.html` - home page and service overview
- `about.html` - professional background and working approach
- `services.html` - bookkeeping, financial analysis, tax, service business, and ecommerce services
- `credentials.html` - QuickBooks, Xero, and A2X credentials
- `contact.html` - contact details and consultation call to action

## Publishing

Publish the contents of this folder with GitHub Pages. The website currently uses `paul@manalangaccounting.com` as the contact email, matching the existing website. Update that address in `contact.html` if a different inbox should receive inquiries.
